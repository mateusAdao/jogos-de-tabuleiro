Sobre o Projeto

Objetivo do site

este site foi criado como atividade pratica da disciplina de Linguagem de Script para Web com foco em estrutura semantica.

A ideia principal e apresentar jogos classicos de mesa de forma simples para quem esta comecando agora nesse hobby

Atualizado em 25 de novembro de 2026.

Tecnologias usadas

Toda a estrutura das paginas utiliza HTML5 semantico sem uso de frameworks externos ou bibliotecas pesadas.

o visual foi montado em um arquivo css separado para manter o codigo organizado e facil de dar manutencao.
